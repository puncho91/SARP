# Semera Airport & ARFF Renovation Project - Ultimate Master Hub
CRTEC On-Site Engineering & Supervision Portal

## Overview
This single-file web application provides comprehensive BOQ tracking, live financial recalculation, remaining works analysis, snag management (SI 017), daily progress and photo transmittal reporting, and discipline quality checklists for the Semera Airport Renovation Project.

- **Total Contract Value**: 1,294,631,965.36 ETB
- **Total Executed Value**: 1,057,006,874.03 ETB
- **Overall Progress**: 81.65%

## Deployment on GitHub Pages
1. Upload `index.html` to the root of your GitHub repository.
2. Enable GitHub Pages in your repository settings (Branch: `main`, Folder: `/ (root)`).
3. Access your live portal instantly!
